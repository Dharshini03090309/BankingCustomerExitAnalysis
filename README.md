# Banking Customer Exit Analysis

**A notebook-based data analysis project focused on customer exit/churn in banking.**

## Overview
Understanding why customers leave is an important part of customer analytics. This project explores a banking customer-exit dataset through a Jupyter notebook, with a separate project report.

## Project files
- [Analysis notebook](./24MSP3070__BANKING_CUSTOMER_EXIT_ANALYSIS.ipynb) — the analysis and notebook outputs.
- [Project report (GitHub attachment)](https://github.com/user-attachments/files/18147670/24MSP3070_FINALREPORT_DHARSHINIM.pdf) — supporting documentation.

## Areas of focus
- Understanding the customer data and the exit-related problem.
- Using notebook-based analysis to investigate relationships in the data.
- Presenting observations in a structured report.

## How to explore
Open the notebook directly on GitHub to review the analysis, or download it and run it in a compatible Jupyter environment with the required data and dependencies.

> This is a portfolio/learning project; review the notebook and report for the actual methods and findings rather than treating the analysis as a production banking model.
